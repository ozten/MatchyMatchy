# M1 design — capture + visual diff skeleton

Spec: `docs/prds/page-pair-diff-spec.md` §12 M1, governed by §3 (architecture, determinism),
§4 (capture), §5 (anchors), §7 (contract), §11 (visual diff), §15 (invariants).

## 1. Scope and DoD

M1 ships: TS capture producing `CaptureBundle` (screenshots + stabilization + environment
fingerprint + a minimal semantic node stream), Rust analyze producing `old.png/new.png/diff.png`,
page-height delta, and a `DiffResult` with `visual_region_changed` / `page_height_changed`,
`matchy` orchestrating end-to-end, and `matchy doctor`.

DoD (spec §12, verbatim): two URLs → artifacts + valid DiffResult JSON validated against schema;
environment fingerprint recorded in bundles; runtime requirements documented in the README;
`matchy doctor` reports this machine healthy.

**Mapped testbed fixtures (must be green to close M1):**

| variant | port | acceptance |
|---|---|---|
| v01-identical | 3001 | `status: pass`, zero issues (`maxIssues: 0`) |
| v02-banner-added | 3002 | required: `visual_region_changed` with `locator.anchors.text` containing `"20% off"`; `page_height_changed` accepted knock-on; status pass/warn/fail |
| v13-render-equivalent | 3013 | `status: pass`, zero issues — no visual/style/missing issue of any kind |

All other variants stay red until their milestones; `make fixture VARIANT=...` works for them but
`make verify` gates only on the M1 set.

**M1 includes minimal page-model extraction.** v02's required issue must carry the banner text in
`locator.anchors` (testbed `expected-issues.schema.json`: anchor matchers run against
`locator.anchors`). Regions therefore need node linking in M1. Full matching stays in M3; M1 only
extracts the node stream and links regions to overlapping nodes.

Not in M1: hygiene (M2), matching/content diff (M3), computed-style capture+diff (M4 —
`computedStyles` is `{}`), sequence diff (M5), a11y (M7 — `a11y.violations` is `[]`),
clustering/baseline/HTML/MD renderers (M8 — `clusters: []`, `suppressed: {count:0, ids:[]}`).

## 3. Contract (JSON Schema 2020-12, the product — review-critical)

### 3.1 `CaptureBundle` (spec §4.5)

```jsonc
{
  "schemaVersion": "1.0",
  "capturedAt": "<ISO8601>",                  // excluded from all golden comparisons
  "viewport": { "name": "desktop", "width": 1440, "height": 1000, "dsf": 1 },
  "environment": { "os": "linux", "chromiumBuild": "<browser.version()>", "playwright": "1.60.0", "dsf": 1 },
  "determinism": {
    // every step: "ran" | "failed" | "skipped"
    "animationsDisabled": "ran", "reducedMotion": "ran", "timeFrozen": "ran",
    "randomStubbed": "ran", "fontsReady": "ran", "imagesDecoded": "ran",
    "lazyLoadPass": "ran", "settled": "ran",
    "clicked": [], "hidden": [], "masked": [],          // selectors actually applied
    "retriedWithoutTimeFreeze": false
  },
  "page": {
    "url": "...", "finalUrl": "...", "redirectChain": [], "statusCode": 200,
    "title": "...", "metaDescription": "...", "canonical": null, "lang": "en",
    "pageHeight": 6420,                       // documentElement.scrollHeight post-stabilization
    "nodes": [ /* SemanticNode[] */ ],
    "landmarks": ["banner","navigation","main","contentinfo"],
    "network": { "requests": [ { "url": "...", "status": 200, "type": "image", "failed": false } ] },
    "console": [ { "level": "error", "text": "..." } ],
    "a11y": { "violations": [] }
  },
  "computedStyles": {},                       // M4
  "screenshots": { "fullPage": "desktop/old.png", "viewport": "desktop/old-vp.png" }
  // screenshot paths are relative to the BUNDLE FILE's own directory's parent (the out dir)
}
```

`SemanticNode` (spec §6.1): `id` (`node_<seqIndex>`), `kind`
(`heading|text|link|button|image|form|field|landmark|generic`), `role`, `text`, `accName`,
`href` (absolute, resolved), `imageAlt`, `bbox` `[x,y,w,h]` (CSS px, page coords, dsf=1 so PNG px
== CSS px), `seqIndex` (document order, 0-based), `anchors` `{text, role, href, alt, ariaLabel,
nearestHeading, landmark, ordinalInLandmark}`, `cssSelector` (internal, landmark-relative).
Nullable string fields are `null`, not absent. All page-derived strings length-capped (500,
config) and control-char-stripped at extraction (§7.5).

### 3.2 `DiffResult` (spec §7 — follow the spec JSON verbatim)

Top-level exactly as spec §7: `schemaVersion "1.0"`, `toolVersion` (crate version), `runId`
(ISO8601 of run start; excluded from goldens), `oldUrl`, `newUrl`, `parityProfile`, `status`,
`agentSummary {fixableNow, byType, clusterCount, topFixes}`, `scores` (all seven categories),
`viewports [{name, status, issues[ids], artifacts{old,new,diff}}]`, `issues`, `clusters: []`,
`suppressed {count:0, ids:[]}`, `determinism {old, new}`, `artifacts {old,new,diff}` (primary =
first configured viewport).

Multi-viewport: issues concatenated (viewport recorded per issue); per-category score = min over
viewports; top-level `determinism.old/.new` = per-step worst across viewports (failed > skipped >
ran).

`Issue` exactly as spec §7.1. M1 notes:
- `remediation` is nullable; M1 visual issues carry none (no deterministic fix is known).
- `evidence` for `visual_region_changed`: `{"visual": {"regionBbox":[x,y,w,h],
  "changedPixels": N, "regionChangedRatio": r, "pageChangedRatio": p}, "artifacts":
  {"oldCrop": "...", "newCrop": "...", "diffCrop": "..."}}`. No `evidence.match` until M3.
- `evidence` for `page_height_changed`: `{"old": {"pageHeight": H1}, "new": {"pageHeight": H2},
  "delta": H2-H1}`.
- `goal`: `"G4"` for visual issues only when a style linkage exists (M4); M1 emits `null`.

**Issue id (spec §7.1, frozen here):** `"issue_" + hex12(sha256(canonical))` where canonical =
fields joined by `\x1f` in this exact order:
`type, viewport, anchors.text, anchors.role, anchors.href, anchors.alt, anchors.ariaLabel,
anchors.nearestHeading, anchors.landmark, str(anchors.ordinalInLandmark), styleProperty` —
null → empty string. Never includes bbox/selector/score/paths.
**Collision rule** (multiple anchor-less regions hash identically): after hashing, sort colliding
issues by `(bboxNew.y, bboxNew.x, bboxOld.y, bboxOld.x)` and suffix `-2`, `-3`, … to all but the
first. Deterministic; flagged for M6 revisit.

**Ordering (spec §7.2):** fix value = severityWeight × confidence × localityBonus;
severityWeight: info 1, warning 2, error 4, critical 8. localityBonus from anchor strength
(spec §5): high 1.0 = any of text/href/alt/ariaLabel non-empty; medium 0.7 = only
nearestHeading+landmark; low 0.4 = neither. Sort descending, total-order tie-break ascending `id`.

**Status:** any post-profile severity critical/error → `fail`; warning → `warn`; else `pass`.
`error` reserved for runs that emit a DiffResult despite a tool-level failure (unused in M1 happy
paths). Profile `content-structure` (default): visual category → severity `info`;
`strict-visual`: visual → `error`. `load_error` is `critical` under both.

**Scores:** `visual = 1 − pageChangedRatio` (common-area ratio, clamped [0,1]); all other
categories `1.0` in M1 (their differs don't exist yet).

`agentSummary.fixableNow` = count(severity ≥ warning AND anchor strength ≥ medium AND remediation
non-null) — 0 in M1. `byType` = BTreeMap counts. `topFixes` = first 5 issue ids in sorted order.

## 4. Capture (TypeScript, Playwright 1.60.0 pinned exactly)

**Process protocol (spec §3.1):** `capture.cjs` takes no flags. It reads one `CaptureConfig` JSON
from stdin, writes artifacts under `outDir`, prints one JSON line to stdout:
`{"ok":true,"bundlePath":"..."}` or `{"ok":false,"error":{"code":"...","message":"..."}}`, exit
0/1. `CaptureConfig`:

```jsonc
{
  "mode": "capture",                          // or "doctor"
  "url": "...", "outDir": "/abs/path", "prefix": "old",       // old | new
  "viewport": { "name": "desktop", "width": 1440, "height": 1000, "dsf": 1 },
  "stabilization": {
    "freezeTime": true, "fixedTime": "2026-01-01T00:00:00.000Z",
    "stubRandom": true, "randomSeed": 1337,
    "networkIdleTimeoutMs": 15000, "settleMs": 1000, "lazyScrollStepPx": 800
  },
  "hideSelectors": [], "maskSelectors": [], "clickBeforeCapture": [],
  "maxTextLength": 500,
  "redactParams": ["token","sig","signature","key","auth","apikey","access_token"]
}
```

**Doctor mode** returns `{"ok":true,"node":"v24...","playwright":"1.60.0",
"chromium":{"ok":true,"version":"..."}}` by launching+closing Chromium headless.

**Stabilization sequence (§4.2, each step try/catch → status recorded):**
1. Context: viewport, dsf, locale `en-US`, timezone `UTC`, fixed UA suffix, colorScheme light.
   Never `--no-sandbox`.
2. `emulateMedia({reducedMotion:'reduce'})`; init script seeding `Math.random` (LCG, seed from
   config); `clock.install({time: fixedTime})` when freezeTime.
3. `goto(url, waitUntil:'load')` → `waitForLoadState('networkidle',
   {timeout: networkIdleTimeoutMs})`.
   On networkidle timeout with freezeTime on: close page, retry ONCE with freezeTime off; record
   `timeFrozen:"skipped"`, `retriedWithoutTimeFreeze:true` (analyze downgrades confidence).
4. `addStyleTag` animation kill: `*,*::before,*::after{animation:none!important;
   transition:none!important} html{scroll-behavior:auto!important;caret-color:transparent}`.
5. `clickBeforeCapture` selectors (each optional — absence is not failure).
6. If clock installed: `clock.runFor(settleMs)` to flush page timers deterministically.
7. `document.fonts.ready`; decode all visible `<img>` (per-image decode rejection — e.g. a 404
   image — is page reality, recorded via network requests, NOT a step failure).
8. Lazy-load pass: scroll to bottom in `lazyScrollStepPx` steps, back to top; re-wait fonts +
   images; `clock.runFor(250)`.
9. Apply `hideSelectors` (`visibility:hidden!important`) and `maskSelectors` (neutral fill
   `#808080`, `color:transparent`, `background-image:none`, layout preserved). Record applied
   lists.
10. Extract page model (below), read `pageHeight = documentElement.scrollHeight`.
11. Screenshots: full page → `<viewport>/<prefix>.png`, viewport → `<viewport>/<prefix>-vp.png`
    (`animations:'disabled'`).
12. Network/console recorded from step 3 onward; redact `Authorization`/`Cookie`/`Set-Cookie`
    (never stored) and configured query params (`…redacted…`) before writing.
13. Write bundle `<viewport>/<prefix>.bundle.json`; zod-validate before writing; print path.

**Page-model extraction (in-page, single `page.evaluate`):**
- Walk DOM in document order. Visible = `el.checkVisibility({checkOpacity:true,
  checkVisibilityCSS:true})` AND bbox area > 0 AND bbox intersects `[0,0,docWidth,scrollHeight]`.
- Classification precedence: heading (h1–h6) > link (`a[href]`) > button (`button`,
  `[role=button]`, `input[type=submit|button]`) > image (`img`) > field
  (`input|select|textarea`) > form (`form`) > text (element with ≥1 direct child text node with
  non-whitespace content) > skip. A classified element still allows descendants to classify
  (outer text + inner link both emitted; outer has lower seqIndex).
- Normalization: NBSP→space, collapse whitespace, trim, strip C0/C1 controls, cap at
  `maxTextLength`.
- `text` = normalized `innerText`; `accName` = aria-label || alt || normalized innerText.
- `href` resolved absolute; `imageAlt` from `alt`.
- `nearestHeading` = text of the most recent heading node in document order (null before first).
- `landmark` = nearest ancestor of `header→banner, nav→navigation, main→main, footer→contentinfo,
  aside→complementary, form→form, [role=...] equivalents`; null otherwise.
- `ordinalInLandmark` = 1-based count of prior nodes with same (kind, anchors.text) in the same
  landmark, including self.
- `cssSelector` = landmark-relative `tag:nth-of-type()` chain (internal only).
- `bbox` = `getBoundingClientRect()` + scroll offsets, rounded to integers (floor x/y, ceil w/h).

## 5. Analyze (Rust)

### 5.1 Determinism rules (spec §3.3 — enforce in review)
- No `HashMap` anywhere output-affecting: `BTreeMap` or collect-and-sort.
- Single-threaded pixel pass in M1 (perf is fine at ~9M px; parallelism deferred until it can be
  reassembled deterministically).
- All sorts define total orders; final tie-break = node/issue id, then bbox (y,x).
- `serde_json` (ryu) for float serialization; no float accumulation across unordered iteration.
- `matchy analyze --old-bundle A --new-bundle B --out D` re-runs analysis from bundles on disk —
  the determinism spot-check and (later) byte-exact golden suite run through this subcommand.
  `matchy run` uses the same code path.

### 5.2 Visual diff (spec §11)
- Decode both fullPage PNGs. Widths must match (same viewport config; mismatch = tool error,
  exit 2).
- `commonHeight = min(hOld, hNew)`. Compare ONLY `y < commonHeight`. The remainder is reported
  solely via `page_height_changed` — never as changed pixels.
- Per-pixel: pixelmatch-style YIQ perceptual delta on RGB(A-composited-on-white); changed when
  `delta > pixelThreshold` (default 0.1, config). Antialiasing detection: none in M1
  (same-machine fixtures; revisit at M6 with real pairs).
- `pageChangedRatio = changed / (W × commonHeight)`.
- **Region clustering:** mark 16×16-px grid cells containing ≥1 changed pixel; 8-connected
  components over cells via union-find in row-major order; region bbox = tight bbox of changed
  pixels in the component; region area = bbox w×h. Regions sorted by (y, x).
- **Emission rule:** emit one `visual_region_changed` per region iff region area ≥ `minRegionArea`
  (2500 px², config) AND `pageChangedRatio ≥ visualThreshold` (0.005, config).
- `page_height_changed` emitted iff `hOld != hNew` (PNG heights; bundle `pageHeight` recorded in
  evidence).
- `diff.png`: grayscale-faded old as base over common height, changed pixels solid red, area below
  common height (on the taller side's extent) neutral gray hatch — visibly "not compared".
- Per-issue crops: region bbox (clamped, +8px pad) cropped from old/new fullpage PNGs and from the
  diff → `<viewport>/issues/<issueId>_{old,new,diff}.png`.

### 5.3 Region → anchor linking (M1 rule, drives v02)
Candidates = NEW-page nodes whose bbox∩region ≥ 30% of node bbox area and which have a
distinctive anchor (non-empty `text`, else `href`/`alt`/`ariaLabel`). Pick **minimum `seqIndex`**
(document order; tie-break node id). Rationale: added content (v02 banner) precedes the displaced
content it shifted, so document order deterministically selects the cause over the symptoms, and
it degrades sanely for in-place changes (picks the region's first text). If no new-page candidate,
repeat over old-page nodes. If none, anchors all-null (strength low, localityBonus 0.4). The
chosen node also supplies `nearestHeading`/`landmark`/`ordinalInLandmark`/`role`,
`cssSelectorOld/New` (old/new side respectively when available), `bboxOld/bboxNew` = region bbox,
`seqIndexOld/New` from the matched-side node (null on the other side — no matcher until M3).

### 5.4 Confidence (fixed constants)
Base: `visual_region_changed` 0.9, `page_height_changed` 0.95, `load_error` 0.99. Multipliers
(mechanical, §3.3): environment fingerprint mismatch between bundles → ×0.5 (plus a top-level
warning recorded as an `info` console note in DiffResult? No — M1: multiplier only);
`timeFrozen`/`lazyLoadPass`/`fontsReady` ∈ {failed, skipped} on either bundle → ×0.8 (applied
once); issue's region overlaps any masked selector's node? — not resolvable in M1, deferred.
Round confidence to 4 decimals at emission (stable formatting).

### 5.5 CLI + orchestration
`matchy --old U --new U --out DIR [--viewport name=WxH ...] [--profile P] [--hide CSV]
[--mask CSV] [--click CSV] [--no-freeze-time] [--no-stub-random] [--fail-on
info|warning|error|critical|never] [--json]` — defaults: viewports `desktop=1440x1000` AND
`mobile=390x844` (spec §4.1), profile `content-structure`, fail-on `error`, JSON always written
(`--json` reserved/no-op-true in M1).
Subcommands: `matchy doctor`, `matchy analyze` (internal, §5.1).

Per viewport: spawn `node capture.cjs` old then new (sequential, deterministic), config via
stdin. Capture failure handling: both sides fail → exit 2 with structured stderr; one side fails →
emit DiffResult with single `load_error` (critical, category technical, message includes child
error; locator anchors null) for that viewport, status fail.
Resolution order for `capture.cjs`: `MATCHY_CAPTURE_PATH` env → sibling of the binary →
`packages/capture/dist/capture.cjs` (dev). Write `DiffResult` to `out/diff-result.json`.
Exit codes: 0 below fail-on; 1 ≥ fail-on; 2 tool/runtime error.

`matchy doctor`: checks node on PATH ≥ 20, capture.cjs resolvable, then capture doctor-mode
(playwright version, Chromium launch). Prints status table + exact remediation commands
(`npx playwright install chromium` etc.). Exit 0 healthy, 1 not.

### 5.6 Config defaults (constants module; config file deferred)
`pixelThreshold 0.1, minRegionArea 2500, visualThreshold 0.005, gridCell 16, regionNodeOverlap
0.3, cropPad 8, severityWeights {info:1,warning:2,error:4,critical:8}, localityBonus
{high:1.0,medium:0.7,low:0.4}`.

## 6. Test harness

### 6.1 `make fixture VARIANT=vNN` → `testbed/check-fixture.py`
1. Ensure servers up (reuse run-all.py start semantics; leave running).
2. old = `http://localhost:3000/`, new = manifest `urlUnderTest` or `http://localhost:<port>/`.
3. Run `matchy --old ... --new ... --out testbed/.runs/<variant> --viewport desktop=1440x1000`
   (single viewport pinned for the harness; spec default stays both).
4. Validate `diff-result.json` against `contract/diff-result.schema.json` and each bundle against
   `contract/capture-bundle.schema.json` (python `jsonschema`).
5. Evaluate `expected-issues.json`: matcher semantics — `type` exact or `*` prefix-wildcard;
   `anyOfTypes` any-of; `anchors.*Contains` case-sensitive substring against `locator.anchors`
   (`landmark`/`role` exact); `evidence.property` exact key in `evidence.old`/`evidence.new`/
   remediation property; `from/to/old/newContains` substring against the corresponding evidence
   values (stringified); `minSeverity`/`maxSeverity` against severity rank. Required: each entry
   satisfied by ≥1 distinct issue (greedy in order, each issue consumed once). Forbidden: no
   emitted issue satisfies any matcher. `status` ∈ allowed set; `maxIssues` cap.
6. Print verdict table; exit 0/1.

### 6.2 `make verify`
1. `cargo build --release` + `cargo test` (workspace).
2. `npm ci --prefix packages/capture` (if needed) + `npm run build` + `npm test`.
3. `python3 testbed/run-all.py check`.
4. `check-fixture` for v01, v02, v13 (the M1 gate set).
5. Golden comparison: for each `testbed/goldens/<variant>.diffresult.json`, compare against the
   fresh run via `testbed/compare-golden.py`: deep-compare excluding keys `runId`, `capturedAt`,
   and any `*Crop`/artifact path values' existence-only check; floats equal within 1e-4; arrays
   order-sensitive.
6. Determinism spot-check: `matchy analyze` twice over the v02 bundles → byte-identical
   `diff-result.json` after stripping `runId` (verified with a scripted byte compare).
Exit 0 = all green.

### 6.3 Unit tests (must exist, named in briefs)
Rust: issue-id stability under jittered bbox/score; id collision suffix determinism; common-height
no-false-flood (synthetic tall/short images); region clustering on synthetic masks (split + merge
+ minRegionArea boundary); YIQ threshold sanity; ordering total-order; status/profile mapping;
emitted DiffResult validates against `contract/diff-result.schema.json` (jsonschema crate, dev-dep).
TS (vitest): normalization (NBSP/controls/cap); redaction of query params + headers; zod
CaptureBundle accepts a known-good sample and rejects a missing-fingerprint sample.

## 7. Risks / decisions taken
- **R1** v02 may cluster into one giant region (banner shifts everything below): the §5.3
  min-seqIndex rule still anchors it to the banner text. If clustering instead splits regions,
  the banner region independently anchors correctly. Both outcomes satisfy intent.
- **R2** v13 claims byte-identical rendering; any nonzero pixel diff there is a capture
  stabilization bug — fix code, never the expectation.
- **D1** Issue-id collision suffix rule (§3.2) is a spec gap, documented here; revisit at M6.
- **D2** `matchy analyze` subcommand is tool-internal, added for determinism verification and the
  §13.3 analysis-golden suite.
- **D3** Harness pins the desktop viewport; the CLI default remains desktop+mobile per spec.
